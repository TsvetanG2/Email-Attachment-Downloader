## [1.0.0] - 2025-12-30

### Added

- Initial release.
- Multi-provider support: connect to Gmail or Outlook/Hotmail over IMAP.
- Advanced filtering by sender, subject, and date range with a calendar picker.
- File-type selection (PDF, images, documents, spreadsheets, presentations,
  archives).
- Preview window to review and select specific emails before downloading.
- Auto-rename patterns (date prefix, sender prefix, subject prefix, etc.).
- Threaded downloads with a real-time progress bar and activity log.
- Modern dark UI built with CustomTkinter.
- Windows installer (`EmailAttachmentDownloader_Setup_1.0.0.exe`).
